What is WLAN Pi?

WLAN Pi is a community-driven, open-source Wi-Fi analysis tool built on single-board computers. WLAN professionals rely on WLAN Pi to scan, test, monitor, and troubleshoot wired and wireless networks.

Built for WLAN professionals, by WLAN professionals.

WLAN Pi OS

WLAN Pi OS is an opinionated Linux distribution aimed at giving WLAN professionals a better out-of-the-box experience. Built on Raspberry Pi OS, the distribution ships the tools, drivers, and sensible defaults that are normally assembled by hand, so a freshly flashed device is useful on first boot.

Open source and contributions

Everything here is developed in the open on GitHub. Contributions of every size are welcome, from a typo fix to a new app, along with bug reports and feature requests. The best way to get involved is to open an issue or a pull request, or start a discussion with the community.
