What is WLAN Pi?

WLAN Pi is a community-driven, open-source Wi-Fi analysis tool built on single-board computers. WLAN professionals rely on WLAN Pi to scan, test, monitor, and troubleshoot wired and wireless networks.

Built for WLAN professionals, by WLAN professionals.

WLAN Pi OS

WLAN Pi OS is an opinionated Linux distribution designed to provide WLAN professionals with a better out-of-the-box experience. Built on Raspberry Pi OS, which is based on Debian, the distribution ships the tools, drivers, and sensible defaults that are typically assembled manually, making a freshly flashed device useful upon first boot.

Open source and contributions

Everything here is developed openly on GitHub. Contributions of any size are welcome, ranging from typo fixes to new applications, along with bug reports and feature requests. The best way to get involved is by opening an issue, submitting a pull request, or starting a discussion with the community.
